# CineVerse

A mobile-first movie/entertainment website built with pure HTML, CSS, and JavaScript — no frameworks, no backend, hosted free on GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — all styling
- `data.js` — local demo movie data
- `script.js` — search, filtering, modal, watchlist logic

## Local data
All movies live in `data.js`. Edit that file to add, remove, or change titles — no other file needs to change.

## Watchlist
Saved in the browser's `localStorage`, so it's per-device and needs no login or database.
